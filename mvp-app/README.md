# 论文原创表达诊断与优化工具

`mvp-app/` 是一个本地运行的静态前端与 Node.js 代理服务，用于识别论文段落中的模板化、空泛化、证据不足和结构机械等表达质量问题，并记录人工修改建议。

## 功能边界

- 支持粘贴论文文本、按段落诊断、风险标记、人工编辑和 Markdown 报告导出。
- 默认使用浏览器端规则诊断；可选通过本机代理调用 OpenAI-compatible 模型。
- 不承诺降低任何 AIGC 检测分数，不提供规避审查策略，不生成虚构文献、数据、访谈、政策或案例。
- 当前不包含 Word 上传解析、历史记录、账户系统或服务端持久化。

## 环境要求

- Node.js 18 或更高版本（使用内置 `fetch`）。
- 现代浏览器。
- 项目没有第三方运行时依赖，也没有 `package.json`；无需执行 `npm install`。

## 安装与运行

在本目录执行：

```powershell
node server.js
```

浏览器打开 <http://127.0.0.1:8787>。Windows 用户也可运行 `start-site.bat`。

服务默认只监听回环地址，避免同一局域网中的其他设备访问本机代理。若确实需要改变监听地址，可在启动前显式设置 `HOST`；请同时配置防火墙和访问控制。

## 配置模型增强

在页面展开“模型增强”后填写 API Key、Base URL 和模型名。密钥仅随请求发送到本机代理，再由代理发送到你填写的模型地址；仓库不包含密钥。默认不把密钥保存到浏览器 `localStorage`，只有主动勾选“记住到本机浏览器”才会保存。

模型地址必须是完整的 HTTP(S) URL。非本机地址必须使用 HTTPS；不要填写不受信任的地址，也不要在共享电脑上保存密钥。模型服务商的数据留存、跨境传输和训练政策由使用者自行确认。

## 测试

```powershell
node --check server.js
node --check app.js
```

仓库当前没有自动化测试和依赖锁文件。发布前应手工验证规则诊断、模型调用失败回退、报告导出和不同浏览器的界面行为。

## 目录说明

- `index.html`：页面结构和文案。
- `app.js`：规则诊断、交互状态、模型请求和报告导出。
- `styles.css`：界面样式。
- `server.js`：静态文件服务和模型代理。
- `start-site.bat`：Windows 启动脚本。

## 数据与隐私

输入论文内容默认只保存在当前浏览器内存中。启用模型增强后，段落文本会发送到用户配置的模型服务；请不要粘贴未获授权的个人信息、未公开研究材料、健康/财务资料或受保密协议约束的内容。应用没有账户、数据库和服务端历史记录。
