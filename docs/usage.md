# 使用说明

## 本地规则诊断

1. 进入 mvp-app/ 并运行 node server.js。
2. 打开 http://127.0.0.1:8787。
3. 粘贴需要检查的论文文本，选择章节类型、学科和优化强度。
4. 点击开始诊断，在段落列表中查看风险和建议。
5. 可在编辑区人工修改，或将报告导出为 Markdown。

## 模型增强

展开模型设置，填写 API Key、模型地址和模型名后勾选启用。模型地址应使用可信的 HTTPS 地址；本机模型可以使用回环地址。测试连接只使用内置短句，不会把当前论文文本作为测试内容发送。

若模型调用失败，页面保留本地规则结果。缺少真实数据、引用或案例时，工具会要求用户补充，不会自动生成事实。

## 数据清理

应用没有服务端历史记录。若曾勾选保存密钥，点击“清除密钥”或清理该站点的浏览器存储；关闭页面不会自动清除已保存的密钥。
