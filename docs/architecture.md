# 架构说明

## 组件

- index.html 提供输入、配置、结果和编辑界面。
- app.js 在浏览器中完成段落切分、本地规则诊断、状态合并、转义渲染和报告导出。
- server.js 使用 Node.js 内置 http 提供静态文件，并代理 /api/model-test 与 /api/model-diagnose。
- 模型结果按段落请求并与本地规则结果合并；模型失败时保留规则结果。

## 安全边界

服务默认监听回环地址；静态文件访问使用规范化相对路径检查；模型地址要求 HTTP(S)，非本机地址要求 HTTPS，并拒绝常见内网和元数据地址。API Key 只存在于当前请求或用户明确选择的浏览器存储中。

这些检查不能替代生产级认证、速率限制、出口防火墙、DNS 防重绑定和供应商隐私评估。该项目定位是本地 MVP，不是多用户公网服务。

## 数据流

浏览器输入
  ├─ 本地规则诊断 ──> 浏览器内存中的结果
  └─ 可选模型增强 ──> 本机 Node 代理 ──> 用户配置的模型服务
                                      └─> 诊断 JSON 返回浏览器
